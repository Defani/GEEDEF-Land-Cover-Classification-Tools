📖 Gambaran Umum 📖 Overview

GEEDEF adalah alat klasifikasi tutupan lahan berbasis cloud yang berjalan sepenuhnya di dalam Google Earth Engine (GEE) Code Editor menggunakan GEE JavaScript API. Dirancang untuk mempercepat alur kerja pemetaan tutupan lahan terpandu (supervised) skala regional maupun lokal menggunakan citra Sentinel-2A Surface Reflectance (SR) Harmonized.

GEEDEF is a cloud-based, interactive land cover classification tool built entirely within the Google Earth Engine (GEE) Code Editor using the GEE JavaScript API. Designed to accelerate supervised land cover mapping workflows at regional and local scales using Sentinel-2A Surface Reflectance (SR) Harmonized imagery.

Alat ini mengintegrasikan tiga algoritma machine learning yang telah teruji secara ilmiah — Random Forest (RF), Gradient Tree Boost (GTB), dan Support Vector Machine (SVM) — beroperasi di atas ruang fitur 26 variabel (10 band spektral + 16 indeks turunan). Seluruh alur kerja dieksekusi secara server-side pada infrastruktur komputasi terdistribusi Google.

The tool integrates three scientifically established machine learning classifiers — Random Forest (RF), Gradient Tree Boost (GTB), and Support Vector Machine (SVM) — operating over a 26-variable feature space (10 spectral bands + 16 derived indices). The entire workflow is executed server-side on Google's distributed computing infrastructure.

Langkah 1 — Batas Wilayah (ROI) Step 1 — Region of Interest (ROI)

ROI mendefinisikan area spasial untuk pemfilteran koleksi citra, pelatihan classifier, dan kalkulasi luasan. Tersedia dua metode:

The ROI defines the spatial extent for image collection filtering, classifier training, and area calculation. Two methods available:

Metode A — Muat dari GEE Asset

Method A — Load from GEE Asset

  1. Masukkan nama akun atau proyek GEE (cth: ee-defaniarman)
  2. Enter your GEE account or project name (e.g., ee-defaniarman)
  3. Klik 🔄 Refresh Assets untuk mengisi dropdown asset FeatureCollection
  4. Click 🔄 Refresh Assets to populate the FeatureCollection asset dropdown
  5. Pilih SHP batas wilayah dari dropdown, lalu klik 📥 Muat ROI dari Dropdown
  6. Select the boundary SHP, then click 📥 Load ROI from Dropdown

Metode B — Gambar Manual

Method B — Manual Drawing

  1. Aktifkan Drawing Tools (ikon pensil, toolbar kiri atas peta)
  2. Activate Drawing Tools (pencil icon, top-left map toolbar)
  3. Gambar poligon batas area kajian
  4. Draw a polygon defining your study area boundary
  5. Klik 🖊 Gunakan Gambar Peta
  6. Click 🖊 Use Map Drawing Tools
💡 Tip

Untuk kajian skala kabupaten atau lebih besar, gunakan Metode A agar batas administrasi tepat mengikuti data resmi. Pastikan ROI tidak terlalu luas untuk menghindari computation time-out.

For district-scale or larger study areas, Method A is preferred to ensure administrative boundaries match official data. Keep the ROI manageable to avoid computation time-outs.

Langkah 4 — Tambah Kelas & Digitasi Sampel Step 4 — Add Classes & Digitize Training Samples

Opsi A — Import dari SHP Asset (Baru di V3.1)

Option A — Import from SHP Asset (New in V3.1)

  1. Masukkan nama akun GEE → klik 🔄 Refresh
  2. Enter GEE account name → click 🔄 Refresh
  3. Pilih SHP sampel latih dari dropdown
  4. Select the training sample SHP from the dropdown
  5. Klik 📖 Baca Kolom untuk mengisi dropdown kolom atribut
  6. Click 📖 Read Columns to populate attribute column dropdowns
  7. Pilih kolom kode kelas dan kolom nama kelas
  8. Select the class code column and the class name/label column
  9. Klik 🔍 Ekstrak Kelas Unik — baris editable muncul per kelas
  10. Click 🔍 Extract Unique Classes — editable row appears per class
  11. Edit nama & warna, lalu klik 📥 Simpan & Impor Sampel
  12. Edit names & colors, then click 📥 Save & Import Mapped Samples

Opsi B — Entri Manual

Option B — Manual Entry

  1. Ketik nama kelas atau klik dari palet Panel Kiri untuk auto-fill
  2. Type a class name or click from the Left Panel palette for auto-fill
  3. Masukkan kode warna hex (cth: #006400)
  4. Enter the hex color code (e.g., #006400)
  5. Klik ＋ TAMBAH KELAS — kode ditetapkan otomatis
  6. Click ＋ ADD CLASS — codes are assigned automatically
  7. Pilih kelas aktif → gambar titik/poligon sampel di peta
  8. Select active class → draw point/polygon samples on the map
💡 Praktik TerbaikBest Practice

Distribusikan sampel secara spasial. Gunakan beberapa poligon kecil per kelas untuk menangkap variabilitas spektral intra-kelas. Hindari zona transisi atau area ambigu.

Distribute samples spatially. Use multiple small polygons per class to capture within-class spectral variability. Avoid transitional or ambiguous zones.

Langkah 5 — Jalankan Klasifikasi Step 5 — Run Classification

Klik 🚀 JALANKAN KLASIFIKASI. Alat mengeksekusi secara server-side:

Click 🚀 RUN CLASSIFICATION. The tool executes server-side:

  1. Ekstrak nilai spektral (26 variabel) dari sampel via sampleRegions
  2. Extract spectral values (26 variables) from samples via sampleRegions
  3. Bagi sampel menjadi set training & validasi menggunakan randomColumn
  4. Split samples into training & validation sets using randomColumn
  5. Latih classifier pada set training
  6. Train classifier on the training set
  7. Klasifikasikan seluruh piksel di dalam ROI
  8. Classify all pixels within the ROI
  9. Hitung error matrix → turunkan OA & Kappa dari set validasi
  10. Compute error matrix → derive OA & Kappa from validation set
  11. Hitung luasan per kelas via ee.Image.pixelArea() dalam hektar
  12. Calculate per-class area via ee.Image.pixelArea() in hectares

If only manual samples are used (no field-validated asset imported), a −5% penalty is applied to OA and Kappa and flagged in the results panel.

Langkah 6 — Ekspor ke Google Drive Step 6 — Export to Google Drive

  1. Isi nama folder Drive (default: GEE_Export) dan nama file (default: LandCover_DFRF_V3)
  2. Set folder name (default: GEE_Export) and filename (default: LandCover_DFRF_V3)
  3. Pilih resolusi spasial: 10 m, 20 m, atau 30 m
  4. Select output spatial resolution: 10 m, 20 m, or 30 m
  5. Klik ⬆ EKSPOR — GeoTIFF ke Drive
  6. Click ⬆ EXPORT — GeoTIFF to Drive
  7. Pantau di tab Tasks (ikon jam, kanan atas GEE Editor). Klik Run
  8. Monitor in the Tasks tab (clock icon, top-right of GEE Editor). Click Run
📝 Catatan OutputOutput Note

File output adalah raster single-band bertipe integer (nilai piksel = kode kelas), CRS: EPSG:4326. Kompatibel dengan QGIS, ArcGIS, dan semua software GIS utama.

Output is a single-band integer raster (pixel value = class code), CRS: EPSG:4326. Compatible with QGIS, ArcGIS, and all major GIS software.

💡 Tips dan Pemecahan Masalah 💡 Tips and Troubleshooting

Tips Umum

General Tips

  • Uji dengan ROI kecil terlebih dahulu sebelum memproses area luas untuk menghindari time-out.
  • Gunakan Cloud Score+ sebagai metode masking utama untuk wilayah tropis.
  • Untuk kajian mangrove, gunakan komposit Median Dry Season untuk kontras spektral maksimal antara kanopi mangrove dan tambak.
  • Distribusikan sampel secara spasial — hindari mengelompokkan semua sampel di satu lokasi.
  • Untuk SVM kernel RBF, lakukan grid search manual pada kombinasi C dan gamma sebelum klasifikasi final.
  • Untuk dataset sampel terbatas (< 200 per kelas), pertimbangkan rasio split 80/20.
  • Test with a small ROI first before processing large areas to avoid computation time-outs.
  • Use Cloud Score+ as the primary masking method for tropical regions.
  • For mangrove studies, use Median Dry Season composite to maximize spectral contrast between mangrove canopy and aquaculture ponds.
  • Distribute samples spatially — avoid concentrating all samples in one geographic location.
  • For SVM with RBF kernel, perform a manual grid search over C and gamma before the final run.
  • For limited datasets (< 200 per class), consider an 80/20 split ratio.

Fungsi Cloud Masking

Cloud Masking Functions

JavaScript 
function maskByCSPlus(image) {
  return image.updateMask(image.select('cs_cdf').gte(0.60));
}

function maskBySCL(image) {
  var scl = image.select('SCL');
  return image.updateMask(
    scl.neq(3).and(scl.neq(7)).and(scl.neq(8))
       .and(scl.neq(9)).and(scl.neq(10)).and(scl.neq(11))
  );
}

function maskByQA60(image) {
  var qa = image.select('QA60');
  return image.updateMask(
    qa.bitwiseAnd(1 << 10).eq(0)
     .and(qa.bitwiseAnd(1 << 11).eq(0))
  );
}
