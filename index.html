Gambaran Umum Overview

GEEDEF dirancang untuk mempercepat alur kerja pemetaan tutupan lahan secara supervised (terpandu) baik untuk skala regional maupun lokal. Alat ini beroperasi murni pada sisi server (server-side) Google Earth Engine, menghindari kebutuhan spesifikasi perangkat keras lokal yang tinggi.

GEEDEF is designed to accelerate supervised land cover mapping workflows at both regional and local scales. The tool operates purely server-side on Google Earth Engine, avoiding the need for high-end local hardware specifications.

Alat ini memproses dataset Sentinel-2A Surface Reflectance Harmonized dan mengekstrak 26 variabel prediktor (10 band spektral dasar + 16 indeks turunan). Pemodelan klasifikasi menggunakan algoritma Machine Learning standar industri.

This tool processes the Sentinel-2A Surface Reflectance Harmonized dataset and extracts 26 predictor variables (10 base spectral bands + 16 derived indices). Classification modeling utilizes industry-standard Machine Learning algorithms.

Alur Kerja Klasifikasi Utama Main Classification Workflow

Prosedur Sekuensial

Pastikan mengeksekusi parameter pada panel kanan secara berurutan. Melompati urutan akan memicu galat eksekusi pada console.

Ensure execution of parameters in the right panel sequentially. Skipping order will trigger execution errors in the console.

Langkah 1. Penetapan Batas Wilayah (ROI) Step 1. Region of Interest (ROI) Assignment

Sistem mendukung dua metode akuisisi geometri batas:

The system supports two methods for boundary geometry acquisition:

  • Asset Dinamis: Membaca *FeatureCollection* langsung dari penyimpanan pengguna (sangat direkomendasikan untuk presisi administratif).
  • Dynamic Asset: Reading a *FeatureCollection* directly from user storage (highly recommended for administrative precision).
  • Digitasi Layar: Menggunakan alat poligon bawaan GEE pada peta.
  • Screen Digitization: Using GEE's built-in polygon tool on the map.

Langkah 2. Konfigurasi Komposit Citra Step 2. Image Composite Configuration

Parameter AkuisisiFungsi / Rekomendasi Acquisition ParameterFunction / Recommendation
Cloud Score+ (CS+) Masking Metode *masking* mutakhir berbasis AI dari Google. Nilai probabilitas kejelasan piksel (cs_cdf) < 0.60 akan dihapus. State-of-the-art AI-based masking method by Google. Pixel clarity probability (cs_cdf) < 0.60 will be removed.
SCL (Scene Classification) Menggunakan band SCL bawaan ESA. Efektif, namun rentan pada tepi awan tipis dibandingkan CS+. Uses ESA's built-in SCL band. Effective, but vulnerable at thin cloud edges compared to CS+.
Median Reducer Agregasi piksel secara temporal untuk menghasilkan komposit bebas hamburan atmosfer. Temporal pixel aggregation to produce atmospheric scattering-free composites.

Langkah 3. Seleksi Algoritma Klasifikasi Step 3. Classification Algorithm Selection

Tiga algoritma pemelajaran mesin (Machine Learning) yang didukung dengan arsitektur hiperparameter yang dapat disesuaikan:

Three supported machine learning algorithms with adjustable hyperparameter architectures:

Random Forest (RF) — ee.Classifier.smileRandomForest

Metode *ensemble learning* paling stabil. Cocok untuk sebagian besar klasifikasi ruang multi-dimensi. Tingkatkan numTrees (ideal: 200-500) untuk stabilitas konvergensi model.

The most stable *ensemble learning* method. Suitable for most multi-dimensional space classifications. Increase numTrees (ideal: 200-500) for model convergence stability.

Gradient Tree Boost (GTB) — ee.Classifier.smileGradientTreeBoost

Membangun pohon keputusan secara sekuensial untuk mengoreksi *error* pohon sebelumnya. Sangat kuat, namun rentan terhadap *overfitting* jika *learning rate* (shrinkage) terlalu tinggi.

Builds decision trees sequentially to correct the *errors* of previous trees. Very powerful, but prone to *overfitting* if the *learning rate* (shrinkage) is too high.

Support Vector Machine (SVM) — ee.Classifier.libsvm

Menggunakan *Kernel Trick* (default: Radial Basis Function/RBF) untuk memisahkan kelas non-linear. Mengharuskan kalibrasi parameter Cost (C) dan Gamma secara spesifik per studi.

Utilizes the *Kernel Trick* (default: Radial Basis Function/RBF) to separate non-linear classes. Requires specific calibration of Cost (C) and Gamma parameters per study.

Langkah 4. Manajemen Kelas dan Sampel Tatih Step 4. Classes and Training Sample Management

Definisikan skema klasifikasi dengan akurasi. Jika menggunakan fitur Import SHP Asset, pastikan tabel atribut *Shapefile* memiliki kolom khusus yang menampung Kode Kelas (Numerik) dan Nama Kelas (String).

Define the classification scheme accurately. If using the Import SHP Asset feature, ensure the *Shapefile* attribute table has specific columns holding Class Code (Numeric) and Class Name (String).

Langkah 5. Eksekusi Klasifikasi Pemetaan Step 5. Run Mapping Classification

Sistem secara dinamis mempartisi data sampel (default 70% pelatihan, 30% validasi lapangan/pseudo). Menghasilkan matriks konfusi (Confusion Matrix), *Overall Accuracy*, dan estimasi luas hektare.

The system dynamically partitions sample data (default 70% training, 30% field/pseudo validation). Generates a Confusion Matrix, Overall Accuracy, and hectare area estimation.

Langkah 6. Ekspor Produk (GeoTIFF) Step 6. Product Export (GeoTIFF)

Hasil klasifikasi diubah menjadi format tipe data Integer (nilai raster sesuai kode kelas) dengan CRS EPSG:4326. Dieksekusi melalui tab Tasks menuju repositori Google Drive pengguna.

Classification results are converted to Integer data type format (raster value matching class code) with CRS EPSG:4326. Executed via the Tasks tab to the user's Google Drive repository.

Indeks Fungsi dan Arsitektur Sintaks GEE Core GEE Functions and Syntax Architecture Index

Modul GEEDEF dibangun dengan mengoptimalkan fungsi-fungsi fundamental pada API JavaScript Google Earth Engine. Berikut adalah arsitektur teknis pembangun utama sistem ini:

The GEEDEF module is built by optimizing fundamental functions in the Google Earth Engine JavaScript API. Below is the main technical architecture building this system:

API Class / Method Fungsi / Operasi dalam GEEDEF Function / Operation in GEEDEF
ee.ImageCollection()
.filterDate(), .filterBounds()		 Memanggil koleksi mentah COPERNICUS/S2_SR_HARMONIZED dan menyaringnya berdasarkan rentang waktu dan geometri batas studi (ROI). Calls the raw COPERNICUS/S2_SR_HARMONIZED collection and filters it based on the date range and study boundary geometry (ROI).
.map(function) Melakukan iterasi fungsi (misal: algoritma *cloud masking* atau kalkulasi indeks spektral) kepada setiap citra tunggal di dalam koleksi tanpa *looping* *client-side*. Iterates a function (e.g., cloud masking algorithm or spectral index calculation) over every single image in the collection without client-side looping.
.median() *Reducer* spasial temporal. Merangkum ribuan piksel tumpang-tindih menjadi satu nilai tengah (median), menghilangkan anomali spektral (seperti bayangan awan atau asap). Temporal spatial *reducer*. Summarizes thousands of overlapping pixels into a single median value, eliminating spectral anomalies (like cloud shadows or smoke).
.normalizedDifference() Sintaks instan GEE untuk menghitung rasio indeks formula $\frac{A - B}{A + B}$. Mempercepat kalkulasi indeks penting seperti NDVI, NDWI, dan NDBI. Instant GEE syntax to calculate index ratio formulas $\frac{A - B}{A + B}$. Speeds up the calculation of crucial indices like NDVI, NDWI, and NDBI.
.sampleRegions() Fungsi ekstraksi data spasial. Mengambil nilai 26 *band* dari komposit citra tepat pada koordinat titik/poligon sampel latih yang telah ditentukan. Spatial data extraction function. Retrieves the 26 *band* values from the image composite exactly at the predetermined training sample point/polygon coordinates.
.randomColumn() Membubuhkan nilai acak (0 hingga 1) ke setiap fitur sampel. Digunakan untuk proses pemisahan dataset menjadi data latih (*Training Set*) dan data uji (*Validation Set*). Appends a random value (0 to 1) to each sample feature. Used for the process of splitting the dataset into a Training Set and a Validation Set.
ee.Classifier
.train()		 Menginisiasi algoritma pemelajaran mesin yang dipilih (RF, GTB, SVM) dan memerintahkannya untuk 'belajar' pola spektral dari data *Training Set*. Initiates the selected machine learning algorithm (RF, GTB, SVM) and commands it to 'learn' spectral patterns from the *Training Set* data.
.classify() Menerapkan model yang telah dilatih (hasil .train()) kembali ke seluruh luasan spasial komposit citra untuk memprediksi kelas tutupan lahan di setiap piksel. Applies the trained model (result of .train()) back to the entire spatial extent of the image composite to predict the land cover class for every pixel.
.errorMatrix() Mengkomputasi akurasi model dengan membandingkan nilai prediksi model terhadap data *Validation Set* (kebenaran lapangan). Menghasilkan persentase *Overall Accuracy* (OA). Computes model accuracy by comparing model predictions against the *Validation Set* (ground truth) data. Produces the Overall Accuracy (OA) percentage.
ee.Image.pixelArea() Fungsi kartografi dasar yang menghitung luasan aktual setiap piksel (m²) menyesuaikan kelengkungan bumi, digunakan untuk menghitung total hektare per kelas klasifikasi. Basic cartographic function that calculates the actual area of each pixel (m²) adjusting for earth curvature, used to compute total hectares per classification class.
